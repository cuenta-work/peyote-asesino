# El Peyote Asesino — Cubo de Rubik demencial

Sitio homenaje **no oficial** a El Peyote Asesino (Villa Española, Montevideo, desde 1994).
Un regalito de **Fungirak**.

En vivo: https://peyote-asesino.fungirak.com

- Sitio estático: `index.html`, `styles.css`, `app.js` (sin build).
- Tema claro. Toda la tipografía es la familia Rubik; cada época del sitio (1995, 1998, 2021, 2026) cambia colores y letra.
- Radio con los videos oficiales de YouTube (IFrame API), carrusel 3D, gráficos SVG, fondo WebGL de semitono.
- Tempos, tonalidades y energía: estimaciones con librosa sobre las muestras de 30 s de Deezer.
- Deploy automático en Vercel en cada push a `main`.
